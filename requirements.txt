📋 Har Package Ka Kaam (Explanation)



| Package                   | Version | Kya Karta Hai                                                            |
| ------------------------- | ------: | ------------------------------------------------------------------------ |
| **FastAPI**               | 0.115.0 | Backend REST API banane ke liye — routes, endpoints aur request handling |
| **Uvicorn[standard]**     |  0.32.0 | ASGI server — FastAPI application ko run karta hai                       |
| **Ollama**                |   0.4.2 | Python client — local Ollama LLM (Llama 3.2) se communicate karta hai    |
| **Pydantic**              |   2.9.2 | Data validation — request/response models define karta hai               |
| **PyPDF2**                |   3.0.1 | PDF files se text extract karta hai — RAG ke liye                        |
| **sentence-transformers** |   3.2.1 | Text ko vector embeddings mein convert karta hai                         |
| **ChromaDB**              |  0.5.15 | Vector database — embeddings store aur similarity search karta hai       |
| **python-multipart**      |  0.0.12 | File upload support — `multipart/form-data` ke through PDF upload        |


🔧 Installation Command
Backend folder me jaake:


cd backend
pip install -r requirements.txt
Ya virtual environment ke saath (recommended):


cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate

pip install -r requirements.txt
⚠️ Important Notes
Python 3.10+ required hai — kyunki sentence-transformers aur chromadb newer Python versions pe better kaam karte hain.

uvicorn[standard] — square brackets wala part important hai, isse extra dependencies (websockets, httptools, uvloop) install hote hain jo performance better karte hain.

sentence-transformers — ye sabse heavy package hai (~2GB+ download hoga kyunki PyTorch bhi saath aata hai). Pehli baar install me time lagega.

chromadb — ye bhi kaafi dependencies laata hai (duckdb, hnswlib, etc.).

Agar GPU nahi hai to sentence-transformers CPU version hi install karega — koi extra config nahi chahiye.

🚀 Agar Install Me Error Aaye
Error: torch install fail ho raha hai


# CPU-only PyTorch pehle install karo (smaller download)
pip install torch --index-url https://download.pytorch.org/whl/cpu

Error: chromadb build fail


# Build tools update karo
pip install --upgrade pip setuptools wheel

python -m venv venv
venv\Scripts\activate
